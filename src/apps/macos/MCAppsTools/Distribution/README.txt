MCNexus - build evolutivo

Instalação
1. Abra o arquivo DMG.
2. Arraste MCNexus.app para Applications.
3. Na primeira abertura, use Control-clique em MCNexus.app e escolha Abrir.
4. Confirme Abrir novamente se o macOS avisar que o app é de desenvolvedor não identificado.

Avisos esperados
- Este build não é assinado com Developer ID e não é notarizado pela Apple.
- O macOS pode bloquear a primeira abertura. Se isso ocorrer, abra Ajustes do Sistema > Privacidade e Segurança e permita a execução.
- O app pode pedir senha de administrador ao instalar ou remover plugins em /Library/OFX/Plugins.

Privacidade
- O MCNexus processa informações necessárias para licenciamento, entrega do produto, segurança, atualizações e suporte.
- Dados técnicos limitados podem ser processados para segurança, confiabilidade, diagnóstico e melhoria do serviço, conforme descrito na Política de Privacidade.
- Política de Privacidade completa, em português e inglês:
  https://github.com/ciqueira/MCNexus/blob/main/PRIVACY.md

Ao reportar problema, envie:
- Versão do macOS.
- Modelo do Mac e chip (Intel/Apple Silicon).
- Print ou texto exato da mensagem de erro.
- Fingerprint ID mostrado em Diagnostics dentro do app.
