NexKeyRuntime SDK

License decision on the render thread.

The decision is a single atomic read: no lock, no allocation, no syscall, no network, no file I/O, and no JSON parsing. License resolution happens off the critical path, and the certificate is verified locally. C/C++14 with a stable C ABI.

Integration → 
#include <nexkeyruntime/nexkeyruntime.h>

NexKeyRuntimeLicenseHandle *license = nexkeyruntime_license_create();
nexkeyruntime_license_set_product_data(license, PRODUCT_DATA);
nexkeyruntime_license_set_tenant_id(license, "tenant-id");
nexkeyruntime_license_load_local(license);

/* On the render thread: a single atomic read.
     No lock, no allocation, no syscall. */
if (nexkeyruntime_license_render_decision(license)
        == NEXKEYRUNTIME_RENDER_ALLOW) {
    render(frame);
}

Pluggable architecture

Independent connectors.

Each layer is separated by an explicit contract, supporting either the default circuit in production today or external providers as roadmap adapters ship.

  • 1. Checkout connector: native Stripe on the developer's own account today, with legal acceptance recorded per order and idempotent fulfillment. External checkouts (Lemon Squeezy*, Shopify*, Pix*) on the roadmap.
  • 2. Licensing connector: native OpenKey (NexKeyRuntime) with offline Ed25519 certificates and air-gap file activation, or Cryptlex in production today. Custom license engines* on the roadmap.
  • 3. Release source connector: public or private GitHub Releases with short-lived signed download tokens and streaming SHA256 verification. Cloudflare R2*, AWS S3* and GitLab* on the roadmap.
  • 4. Email & in-app notices: transactional key delivery via MailerLite under the developer's support address, plus in-app release and critical notices targeted by host, version and OS.

Continuity

What happens if Nexus stops.

A licensed product does not ask a server for permission to run, so a backend interruption is not a license denial: machines already activated keep working for the whole offline window. The recovery key is generated by the developer and its private half never reaches Nexus infrastructure: already-installed copies accept certificates issued by that key, with no server in the loop.

The document also records what an interruption does stop and what does not exist yet.
