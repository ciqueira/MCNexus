An app for managing OFX plugins.

Nexus provides infrastructure for publishing, licensing, and distributing OFX plugins. MCNexus is the macOS and Windows app used to activate licenses, install plugins, check for updates, and install available previous versions.

Operational contexts

For post-production workflows and OFX developers.

01 / Post-production

Licenses, installation, and versions.

MCNexus centralizes license activation, OFX plugin installation, updates, and access to available previous versions.

  • Automatic installation: downloads and installs OFX files in the directory defined by the operating system.
  • Updates and rollback: identifies published versions and allows an update or an available previous version to be installed.
  • Independent actions: activating or deactivating a license, removing the local key, and removing the plugin are separate operations.
  • License transfer: when the previous installation remains accessible, the license can be deactivated before a new activation. Remote activation resets and activation-limit adjustments remain handled by support.

02 / Developers

Distribution for commercial and open-source OFX plugins.

Nexus configures licensing, releases, and distribution for each project. The integration is reviewed and prepared with the developer.

  • Licensing: OpenKey supports open-source projects. Cryptlex provides hardware-bound commercial licensing. MCNexus validates both models.
  • Commerce: in the current flow, GitHub confirms identity, Stripe processes payment, OpenKey issues the license, and MailerLite sends operational messages. Cryptlex license issuance is not yet part of this flow.
  • External channels: products sold or licensed through configured services can use the MCNexus activation, download, installation, update, and rollback flow.
  • Release management: OpenKey projects use GitHub Releases. Cryptlex products can use releases hosted by the provider. Both models use platform packages and version history.
