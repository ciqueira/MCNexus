Distribution infrastructure for OFX

One app for the operational lifecycle of OFX plugins.

Nexus provides the licensing and distribution infrastructure. MCNexus is the desktop app for macOS and Windows used to activate licenses, install plugins, check releases, update, and return to a previous version.

Operational contexts

For post-production workstations and OFX developers.

01 / Post-production

Installation, licensing, and versions in one place.

Activate licenses, install plugins, receive compatible update notifications, and access previous releases directly in MCNexus.

  • Automatic OFX plugin installation
  • Updates only after confirmation
  • Release history and previous versions when available
Read the user guide →

02 / Developers

Distribute your OFX plugin through MCNexus.

Nexus brings licensing, publishing, and release delivery together for open-source and commercial plugins. Each integration is prepared with the developer.

  • Distribution for macOS and Windows
  • OpenKey for open-source projects and commercial licensing options
  • New releases, updates, and previous versions
