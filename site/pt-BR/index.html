Licenciamento, distribuição e manutenção de plugins OFX

Um aplicativo para gerenciamento de plugins OFX.

O Nexus fornece infraestrutura para publicação, licenciamento e distribuição de plugins OFX. O MCNexus é o aplicativo para macOS e Windows usado para ativar licenças, instalar plugins, verificar atualizações e instalar versões anteriores disponíveis.

Contextos operacionais

Para fluxos de pós-produção e desenvolvedores OFX.

01 / Pós-produção

Licenças, instalação e versões.

O MCNexus centraliza a ativação de licenças, a instalação de plugins OFX, as atualizações e o acesso a versões anteriores disponíveis.

  • Instalação automática: baixa e instala os arquivos OFX no diretório definido pelo sistema operacional.
  • Atualização e rollback: identifica versões publicadas e permite instalar uma atualização ou retornar a uma versão anterior disponível.
  • Ações independentes: ativar ou desativar uma licença, remover a chave local e remover o plugin são operações separadas.
  • Transferência de licença: quando a instalação anterior estiver acessível, a licença pode ser desativada antes de uma nova ativação. A liberação remota de uma ativação e os ajustes do limite de ativações permanecem com o suporte.

02 / Desenvolvedores

Distribuição para plugins OFX comerciais e open source.

O Nexus configura licenciamento, releases e distribuição conforme cada projeto. A integração é revisada e preparada com o desenvolvedor.

  • Licenciamento: OpenKey atende projetos open source. Cryptlex oferece licenciamento comercial vinculado ao hardware. O MCNexus valida os dois modelos.
  • Commerce: no fluxo atual, GitHub confirma a identidade, Stripe processa o pagamento, OpenKey emite a licença e MailerLite envia mensagens operacionais. A emissão de licenças Cryptlex ainda não integra esse fluxo.
  • Canais externos: produtos vendidos ou licenciados por serviços configurados podem usar o fluxo de ativação, download, instalação, atualização e rollback do MCNexus.
  • Gerenciamento de releases: projetos OpenKey usam GitHub Releases. Produtos Cryptlex podem usar releases hospedados pelo provedor. Os dois modelos trabalham com pacotes por plataforma e histórico de versões.
