Infraestrutura de distribuição OFX

Um cliente para o ciclo operacional de ferramentas OFX.

O Nexus fornece a infraestrutura de licenciamento e distribuição. O MCNexus é o cliente para macOS e Windows usado para ativar licenças, instalar plugins, consultar releases, atualizar e retornar a uma versão anterior.

Contextos operacionais

Para estações de pós-produção e desenvolvedores OFX.

01 / Pós-produção

Mantenha deliberadas as versões de plugins nas estações.

Instale pacotes OFX compatíveis no local nativo do sistema, consulte o estado da ativação, aplique atualizações publicadas e retorne a um release anterior quando ainda estiver disponível.

  • Operações separadas para licença e remoção de arquivos
  • Seleção explícita de versão e rollback
  • Procedimentos consistentes entre estações de edição e cor
Ler o guia de operação →

02 / Desenvolvedores

Publique por um modelo de distribuição configurado.

O Nexus atende fluxos OFX open source e comerciais. As integrações são revisadas e configuradas por projeto; ainda não existe onboarding público self-service.

  • OpenKey e licenciamento comercial vinculado ao hardware
  • Pacotes de release por plataforma
  • Entrega protegida, atualizações e versões anteriores
