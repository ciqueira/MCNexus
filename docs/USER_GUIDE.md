MCNexus centralizes plugin installation, licensing, version management, and updates for post-production workstations.

## Installing Plugins

The version of MCNexus installed on the workstation places OFX files in the native directory defined by the operating system and used by editing and color-grading applications.

## License Management

Commercial licenses use hardware-bound activation. License activation, deactivation, key removal, and plugin file removal are handled as separate actions.

A license can be transferred between computers when an activation is available within the license limit. Requests to release or adjust activations must be submitted through [GitHub Issues](https://github.com/ciqueira/MCNexus/issues).

## Updates

MCNexus monitors published releases. When a stable version or security fix becomes available, the application displays an update notification and allows the new version to be installed.

## Rollback

The release history allows a previous plugin version to be installed when an older project requires it. MCNexus replaces the plugin files automatically.

## Installation Recovery

The application provides retry and cancel actions when an installation, update, or rollback fails.

## Support

Use the appropriate [GitHub Issues form](https://github.com/ciqueira/MCNexus/issues/new/choose) for:

- MCNexus installation, update, launch, or removal problems;
- plugin installation, update, rollback, or removal problems;
- license activation or availability problems;
- general support.

Include the operating system and version, the MCNexus version, the affected plugin, the observed behavior, and available diagnostics. Do not publish a complete license key.

GitHub Issues are public. Send personal-data requests to [nexus@magnociqueira.com.br](mailto:nexus@magnociqueira.com.br).
