O MCNexus centraliza a instalação de plugins, o licenciamento, o gerenciamento de versões e as atualizações das ilhas de pós-produção.

## Instalação de Plugins

O aplicativo MCNexus instala os arquivos OFX no diretório nativo correspondente ao sistema operacional, utilizado pelos softwares de edição e correção de cor.

## Gerenciamento de Licenças

As licenças comerciais utilizam ativação vinculada ao hardware. A ativação, a desativação, a remoção da chave e a remoção dos arquivos do plugin são tratadas como ações separadas.

Uma licença pode ser transferida entre computadores quando houver uma ativação disponível dentro do limite da licença. Solicitações para liberar ou ajustar ativações devem ser enviadas pelo [GitHub Issues](https://github.com/ciqueira/MCNexus/issues).

## Atualizações

O MCNexus monitora os lançamentos publicados. A disponibilidade de uma versão estável ou correção de segurança gera uma notificação com a opção de instalação.

## Rollback

O histórico de lançamentos permite instalar uma versão anterior quando um projeto antigo exige essa versão. A substituição dos arquivos do plugin é executada automaticamente pelo MCNexus.

## Recuperação de Instalação

Falhas de instalação, atualização ou rollback apresentam ações para nova tentativa ou cancelamento.

## Suporte

O [GitHub Issues](https://github.com/ciqueira/MCNexus/issues/new/choose) contém formulários para:

- problemas de instalação, atualização, inicialização ou remoção do MCNexus;
- problemas de instalação, atualização, rollback ou remoção de plugins;
- problemas de ativação ou disponibilidade de licenças;
- suporte geral.

O chamado deve incluir o sistema operacional e a versão, a versão do MCNexus, o plugin afetado, o comportamento observado e os diagnósticos disponíveis. Chaves de licença completas não devem ser publicadas.

O GitHub Issues é público. Solicitações sobre dados pessoais devem ser enviadas para [nexus@magnociqueira.com.br](mailto:nexus@magnociqueira.com.br).
